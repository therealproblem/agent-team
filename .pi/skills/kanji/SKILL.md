# Kanji Study

Use for kanji-focused study: readings, components, mnemonics, compound words.

## Per-kanji output

```
漢 (kan)
JLPT: N3
Meaning: Han / Chinese
Readings:
  on:  カン
  kun: —
Components: 氵 (water) + 莫 (do not / vast)
Common compounds:
  漢字 (かんじ) — kanji
  漢方 (かんぽう) — Chinese medicine
Mnemonic: <if useful — concrete, vivid, ≤ 1 sentence>
Stroke count: 13
```

## Rules

- Always state the JLPT level.
- Order readings on → kun. Mark どちらでも (either) where applicable.
- Compounds are the most useful real-world payoff — pick 2–4 high-frequency examples per kanji, not the rare/literary ones.
- Mnemonics are optional. Only include when one is genuinely useful — a forced mnemonic is worse than none.
- Components are a learning aid, not a strict etymology. Don't fake folk etymology if you don't know it.

## Drilling

- Reading drills: present the kanji in a compound, ask the user for the reading.
- Meaning drills: present the kanji standalone, ask for the meaning.
- Production drills: present meaning + reading hint, ask the user to write the kanji (recall, not recognition).
