# Clarifier

Use to ask follow-up questions that fill gaps in a trade journal entry. One question at a time, picking the most informative gap.

## Priority of gaps to fill (highest first)

1. **Emotion** — least likely to be self-reported, most useful for pattern-watching. If absent, ask first.
2. **Why now** — what specifically triggered entry, vs. continuing to watch.
3. **Conviction** and *what would have changed it*.
4. **Adjustments** — if stop/target/size moved, why and when in the trade.
5. **Setup** — only if the user named a setup but didn't describe it concretely.
6. **Outcome reflection** — only after the trade is closed.

## Question style

- Open-ended, not yes/no.
- Specific to the trade, not generic. "Walk me through what you saw at entry" beats "Was it a good setup?"
- Never imply a right answer. "What were you feeling when price hit your stop?" — not "Were you nervous?"
- Never offer a candidate explanation. Don't say "was it because of …" — let the user supply the framing.

## When to stop asking

- After **one** question per session, unless the user invites more. Trader is a student, not an interrogator.
- If the user gives a non-answer or seems done, drop it. The gap stays open; ask again next time.

## Don't

- Don't repeat the same question across sessions if it was already declined. Track which questions the user has waved off in `trades/_clarifier-skipped.md`.
- Don't ask for numbers the user can derive (you can compute R-multiple from entry/stop/exit yourself).
